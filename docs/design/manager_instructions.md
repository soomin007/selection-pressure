# 감독형 전환 · 사전 지침 시트 + 작전타임 + 일정표 (2026-09-11)

> 이 문서는 **구현 계약**이다. 무엇을 만들지와 왜 그런 모양인지만 적는다. 경위는 `session_logs/2026-09-11.md`.
> 레퍼런스 조사(FF12 갬빗 · Dragon Age Origins 전술 · Unicorn Overlord · Gladiabots · Football Manager
> 터치라인 샤우트 · Teamfight Manager 2 라커룸 · 황금 우상 단어 끌기)는 같은 날 세션 로그에 있다.

## 0. 결정 (전부 **[사용자 2026-09-11]**)

1. **애착의 대상은 팀(종)** 이다. 개체 이름은 보류.
2. **알파 탭 조종은 사전 지침으로 바꾼다.** 작전타임에만 지침을 고칠 수 있다.
3. **일정표는 항상 보인다.**
4. **데스크톱 메인.** 모바일 전용 제약 해제. 넓은 화면으로 더 많은 정보를 상시 제공.
5. 지침 방식은 내 추천안 그대로: 문장 틀 하나 · 줄마다 우선순위 · 위에서부터 첫 참인 줄만 실행 ·
   단어는 티어·카드로 늘어남 · 발동한 줄을 화면에 표시 · 프리셋은 채워진 문장 묶음.
   작전타임은 **고정 + 호출**.

## 1. 지침 시트 (sim · `src/sim/instructions.ts`)

**문장 틀은 하나다.** 「[누가] [어떤 때] [무엇을 한다]」. 줄은 위에서부터 읽고, 개체마다 매 틱
**처음으로 성립하는 줄 하나**가 발동한다(FF12 규칙). 맨 아래에는 늘 「모두 · 늘 · 알아서 한다」가
보이지 않게 깔려 있다(화면에는 고정 줄로 보여 준다).

```ts
interface Directive { who: Who; when: PerkWhen; act: Act }
```

| 칸 | v0 단어 | 판정 |
|---|---|---|
| 누가 (`Who`) | `all` 모두 · `strong` 이빨이 센 개체 · `weak` 그 밖의 개체 | `strong` = 무는 힘 ≥ `SIM.raidWarriorAttack`(보스전 전사와 같은 문턱) |
| 어떤 때 (`PerkWhen`) | 카드 특성의 조건 13개를 **그대로 재사용** (늘 · 밤에 · 낮에 · 물가에서 · 수풀에서 · 험한 땅에서 · 배가 절반 아래일 때 · 기운이 넉넉할 때 · 곁에 동료가 적을 때 · 많을 때 · 쫓는 동안 · 달아나는 동안 · 물린 뒤 얼마간) | `perks.whenHolds` · 화면 문구도 `PERK_WHEN_INFO` 그대로. 카드와 지침이 같은 말을 쓴다 |
| 무엇을 (`Act`) | `auto` 알아서 한다 · `hide` 수풀로 숨는다 · `gather` 뭉친다 · `scatter` 흩어진다 | 아래 |

**행동의 실체** (전부 순수 기하 · rng 0 · 시트가 null 이면 블록 통째 스킵 = 기존 세계와 비트 동일):
- `auto`: 이동을 안 덮는다. 발동으로는 센다(「N마리 알아서」).
- `hide`: 걸어 닿는 가장 가까운 수풀 칸(반경 `SHEET.hideRadius`)으로 `navTo`. 이미 수풀 위면 그 칸
  중심에 머문다. **닿는 수풀이 없으면 이 줄은 성립하지 않은 것**(FF12: 대상이 없으면 건너뜀) → 다음 줄.
- `gather`: 팀 무게중심(틱 시작에 한 번 계산)에서 `SHEET.gatherRadius` 밖이면 그쪽으로. 안이면 발동하되
  이동은 안 덮는다(이미 뭉쳐 있음). 팀이 저 혼자면 성립 안 함.
- `scatter`: 무게중심에서 `SHEET.scatterRadius` 안이면 반대쪽으로. 밖이면 발동하되 안 덮는다.

**섞는 법**은 옛 지시 블록 그대로: `desired = desired·(1−pull) + go·pull` (`SHEET.pull`). 위의 자율
판단(도망 · chooseGoal · 배회의 rng 소비)은 **하나도 건너뛰지 않는다.**

**본능은 지침보다 위다.** 도망 > 물고 있는 사냥감 > 금빛 짐승 > **지침** > 배회. 줄은 발동해서 세지만,
그 틱의 이동은 본능이 가져간다(화면에는 「도망 중 N」이 따로 보인다). 이 순서는 옛 지시 블록의
실측 근거(사냥감을 덮으면 사냥 9.0 → 2.5)를 그대로 물려받는다. 방울 우선(지시 중 근처 방울을 먼저 줍는다)도
이동 행동(`hide`·`gather`·`scatter`)이 발동한 개체에게 그대로 산다.

**발동 집계는 판정 자리 한 곳에서만 센다** (`world.sheetFired[i]` · 매 틱 리셋 · known_issues 「화면에
뜨는 숫자를 규칙에서 다시 유도하지 마라」). UI 는 읽기만 한다.

**목소리 반경은 없앤다.** 감독의 말은 팀 전체에 닿는다. 무리 티어의 값어치 `HERD_VOICE` 는
**`HERD_SHEET_ROWS`(쓸 수 있는 줄 수 · 2 → 6)** 로 바뀐다(`tiers.ts` 한 곳). 단어 게이트(열쇠·카드로
단어가 열림)는 v0 에 없다 · 단어 수가 늘 때 함께 넣는다.

## 2. 작전타임 (game · `src/game/game.ts`)

- **멈춤은 `phase` 값 하나를 늘린다**: `"timeout"`. 새 플래그 금지(`game.ts:127-136` 계약 ·
  `closeGeneShop` 처럼 `acc` 를 건드리지 않는다 · 회귀 감지기는 `genePanelPause.test.ts` 를 베낀다).
- **고정**: 보스·대멸종 단계가 시작되는 순간 자동으로 열린다(위협이 화면에 나타난 채 멈춘다 ·
  예산을 안 쓴다). 채집 라운드는 자동으로 안 멈춘다(16초짜리 라운드마다 끊으면 흐름이 죽는다).
- **호출**: 단계마다 `GAME.timeoutsPerStage`(=1)회. 남은 횟수는 화면에 보인다.
- **지침을 고칠 수 있는 때** = `phase ∈ {draft, timeout, shop}` (세계가 서 있는 모든 화면). 관전 중에는 읽기 전용.
- 지침 변경은 세계가 **다시 도는 순간** 판 코드에 기록한다(`{t:"sheet", stage, tick, rows}` ·
  `runCode` 새 태그 · 옛 코드는 그대로 읽힌다). 기록이 없으면 재현이 거짓말이 된다(2026-08-09 탭 사고).

## 3. 일정표 (game getter → UI)

- `game.schedule`: 이 시대 6단계 각각 `{kind, ordinal, seconds, state: done|now|ahead, label, threat}`.
  `SCHEDULE`·`stageIndex`·단계 길이 상수에서 **파생만** 한다(새 진실을 만들지 않는다).
- **보스 종류는 미리 적지 않는다.** `peekBossType` 은 지금 게놈으로 판정하므로 두 칸 앞을 적으면
  카드 한 장에 예고가 거짓이 된다(known_issues 「예고를 얼려서 들고 있어야 한다」의 기전 그대로).
  현재 단계와 4초 전 전광판만 종류를 말한다. 대멸종 종류는 큐가 고정이라 미리 적어도 안전하다.
  (보스도 시대 시작에 얼리는 안은 층위 배려와 맞바꿈이라 뒤로 미룬다.)

## 4. 화면 (`src/ui/*` · 데스크톱 메인)

- **왼쪽 상시 열**: 위에 일정표, 아래에 지침 시트. 시트의 각 줄은 세 칸이고 칸을 누르면 그 칸에 들어갈
  단어 목록이 뜬다(끌어 넣기는 다음). 줄마다 이번 틱 발동 수가 붙는다. 맨 아래 고정 줄 「모두 · 늘 ·
  알아서 한다」. 작전타임 버튼(남은 횟수) · 작전타임 중에는 「경기 재개」.
- 폰은 같은 패널을 아래 서랍으로 접는다(폰은 부차).
- 카메라·전광판은 왼쪽 열만큼 비켜 그린다(세로 `hudSafe` 와 같은 문법으로 좌우를 추가).
- 탭 명령·명령 휠·명령 줄은 **끈다**(입력 배선 제거). 코드 삭제는 3절 뒤 정리 조각에서.

## 6. 하지 말 것

- 규칙을 두 곳에 적지 않는다(발동 수 · 일정표 파생 · 조건 판정 전부 원본 함수 하나).
